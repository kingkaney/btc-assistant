Method

Forecast + ensemble from Open-Meteo (GFS ensemble, blended with HRRR short-range). Probabilities = spread across 31 ensemble members, smoothed with a 1.5°F kernel, integer-rounded per ASOS convention. Each member is a full NWP run that already assimilated current cloud/radar/satellite — the app reads their output, it does not re-simulate physics.

Time-of-high = peak hour of each member's curve. Confidence band = 10th–90th percentile. Resolution authority remains the CLISEA daily report.
